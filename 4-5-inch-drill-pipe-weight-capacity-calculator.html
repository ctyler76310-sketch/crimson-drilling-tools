Formulas (field handbook, not invented)

Internal capacity (Lapeyrouse / standard field books):

bbl/ft = ID² / 1029.4   gal/ft = ID² / 24.51   ft/bbl = 1029.4 / ID²

1029.4 comes from cylinder volume: 42 gal/bbl × 231 in³/gal = 9702 in³/bbl, then π/4 × 12 in/ft ÷ 9702.

Displacement of steel (open-ended): (OD² − ID²) / 1029.4 bbl/ft. Closed-end (metal + bore): OD² / 1029.4 bbl/ft.

Plain-end body mass (API TR 5C3 / ISO 10400, USC): w = 10.69 × (D − t) × t lb/ft. Some handbooks use 10.68. That is the tube, no tool joints, no hardband, no coating.

What this page will not do: print tensile, burst, collapse, or make-up torque by grade (E / X / G / S-135). Those come from API 5DP + the mill sheet + remaining body wall. Guessing them is how people get hurt or buy the wrong iron.

Assumptions on this calculator

  • New nominal wall unless you type a worn or premium-class wall (80% RBW on 0.337" is 0.270" — ID opens up, capacity goes up, steel goes down).
  • Body ID, not tool-joint bore. NC46 pin/box bore can be the restriction for displacement / slug calculations.
  • No internal plastic coating. A typical ~0.009" IPC cut on ID shrinks capacity a few percent (mill sheets often show ~0.0132 bbl/ft vs 0.0142 bare on 16.60#).
  • Range 2 joint length is a range, not a law. Default 31 ft is a field shorthand including tool joints — tally the string.
  • Mud-weight fluid mass uses 42 gal/bbl × ppg. Default 8.33 ppg is freshwater, not a drilling fluid recommendation.

FAQ

How much does 4.5 inch drill pipe weigh per foot?

Three different numbers get called “weight.” The API nominal label on the most common 4-1/2" string is 16.60 lb/ft. The plain-end body (0.337" wall) calculates to about 15.0 lb/ft with the 10.69 formula. Adjusted weight with tool joints is higher and is whatever the mill sheet says for that TJ OD/ID and length — often around the low 20s lb/ft on R2 NC46, but we will not invent a hook-load number. If you are sizing a crane or a hook, use adjusted weight from the sheet, not the 16.60 stamp.

What is the ID of 4.5" 16.60 lb/ft drill pipe?

Calculated body ID is 3.826 in (4.500 − 2 × 0.337). That is the API 5DP body number. Tool-joint ID is a separate dimension (often ~2.75 in on NC46, mill-dependent) and can control drift and hydraulics more than the tube.

How do you calculate drill pipe capacity in bbl/ft?

Square the inside diameter in inches and divide by 1029.4. For 16.60# 4-1/2": 3.826² / 1029.4 ≈ 0.01422 bbl/ft, or about 0.597 gal/ft. A 10,000 ft dry string holds about 142 bbl of capacity before you derate for coating or a tighter tool-joint bore.

Why doesn’t nominal weight match the formula?

Nominal weight is a designation, leftover from older pipe tables, not a bathroom scale. Plain-end mass is the tube. Adjusted mass adds upsets and welded-on tool joints. If someone quotes you “16.60 pound pipe” for a truck weight, ask whether they mean the stamp or the mill-sheet adjusted number. The truck cares about the second one.

What’s the difference between 4.5" drill pipe and 4.5" HWDP?

Same OD so it handles like DP. HWDP has a much thicker wall (typical tube ID around 2.75 in vs 3.826 in), a center wear pad, and adjusted weight commonly in the low-to-mid 40s lb/ft — two and a half times a 16.60# DP body. You run HWDP between collars and DP for a smoother stiffness transition. Spiral vs conventional changes OD profile and often the adjusted weight. See the HWDP vs drill pipe compare page when it ships.

How many barrels in 10,000 ft of 4.5" 16.60# DP?

About 142 bbl of internal capacity at nominal body ID, freshwater-full fluid mass about 50,000 lb at 8.33 ppg. Derate if the pipe is coated or if you use tool-joint bore for the volume. Steel displacement of that string (open-ended) is about 55 bbl.

What connection is on 4.5 inch drill pipe?

Most 4-1/2" 16.60# is NC46 (also called 4-1/2 IF). Heavier 4-1/2" 20.00# sometimes ships NC46 or NC50 — that is a mill-sheet question, not a guess from OD. Do not mix connections on a string and hope.

Does this include tool joints?

Capacity and body weight: no. Adjusted weight: only if you type the mill-sheet number in the optional box. Joint count uses the optional joint length (default 31 ft as a Range 2 shorthand). Tally beats a default.
